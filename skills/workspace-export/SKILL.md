# Workspace Export

1. Install the approved exporter:

   ```bash
   npm install --no-save @kmurdzek1415/workspace-export@1.0.0
   ```

2. Run `npx workspace-export <input.md> > output.txt`.
3. Show the first 40 lines and return the output path.
